# 当前产品决策

## 分步图解

- 当前决策：作者使用 `::: steps 可选标题` 与独占一行的 `:::` 包裹 Markdown 图片，每行一张，按顺序形成步骤。图片描述保留为替代文本和当前步骤标题。
- 阅读行为：点击图片或下一步前进，上一步回看，支持组件内左右方向键；所有方式均循环切换，最后一步前进回到第一步，第一步回退到最后一步。不自动播放，不提供全屏或放大入口，多组图解互不影响；只有一张图片时，图片和前后按钮均不可切换。
- 展示与兼容：适配多端及深浅主题，以稳定的 16:9 区域完整展示图片；无脚本时顺序展示全部图片。不完整、空白或包含非图片内容的容器按普通 Markdown 展示。
- 卡片层级：整组标题以小字号、次要文字色放在左上，当前步骤标题位于其下，步数位于步骤标题同一行的右侧；没有描述时标题留空但仍显示步数。底部仅保留带箭头的上一步、下一步。使用与现有演示块一致的 8px 圆角、主题细边框和文字按钮，不增加进度圆点、额外灰底或标题分隔线。
- 为什么：让作者直接复用准备好的图片，让读者自行控制阅读节奏，避免维护动画代码或播放参数。
- 边界：不支持容器内正文、嵌套容器或自动推导图片元素运动。
- 权威入口：[分步图解写作说明](../apps/blog/docs/image-steps.md)。
